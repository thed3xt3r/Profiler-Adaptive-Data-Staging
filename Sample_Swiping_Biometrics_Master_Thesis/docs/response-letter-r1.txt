> Continuing with the 39% who are US citizens, how do we know their primarily spoken language is English?  It might be, say, Spanish if they got citizenship as adults.  So perhaps a more important identifier is "what language do you speak primarily?"

We mentioned in Section 3.1 that language is “browser language”. > Did every problem use the same data sets?  Or did you balance on target classes within a dataset when testing that target?  I know you state on page 12 that the class distributions are imbalanced for most of the targets.

Yes, each model was trained on the very same data partitions. We have clarified it in Section 3.4.

> Are reported results just on the validation set?  How well did the models do on the training set?

All results are reported on the test set, as usual in Machine Learning experiments. We have clarified in Section 3.4 that the testing partition is held out exclusively for model evaluation, as it represents unseen data and is therefore a more challenging but also a more realistic scenario.

> Were the models robust or was there falloff?

Our experiments show that each target has a preferred model (see Table 1), however the 2-layered bidirectional LSTM or GRU model with 100 units was the most frequent winning architecture. So we can conclude that this model architecture is the most general one overall. Since we already mentioned in Section 6 that the 2-layered bidirectional LSTM or GRU model was preferred, we have added there the number of preferred hidden units as well.

> When you report model accuracy, what data set are you referring to?

We always refer to the same dataset (How We Swipe) and always the testing partition (a random 20% split of the dataset). We have clarified it in Section 3.4.

> For each model, could you show the classification matrix for each so we can see how many were classified as each category by the model? We observed this behavior only when predicting nationality (Fig. 8d) and with LR > 10-3. This means that the models were underfitted, i.e. they did not learn properly. === Reviewer #4 ===

> The model could be modified with Attention mechanism, so that 'more affective learning process could be achieved.  This can be considered as a future work.

Many thanks for the suggestion. Indeed, we have mentioned it in Section 5, where we discuss the limitations and future work.

> It is mentioned that low learning rate makes training process slow. But you have demonstrated your experiments with low learning rate only.

As reported in Section 3.4.1, we experimented with learning rates 10−1, 10−2, 10−3, 10−4 and 10−5, 5 variations in total. A learning rate higher than 10−1 (i.e. 0.1) is unlikely to work because of the Robbins-Monro condition [Ranganath, 2014]. Moreover, when LR > 1, stochastic gradient descent is not guaranteed to converge to a minimum. We have cited [Ranganath, 2014] in the revised version of the manuscript to better justify our choice of LR, in Section 3.4.1.

* R. Ranganath et al. Black Box Variational Inference. In Proc. AISTATS, 2014.
